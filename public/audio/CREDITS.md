# Game sound effects

This directory contains only the selected clips currently used by the game.

- `fantasy-spells/`: JC Sounds, [Fantasy SFX Pack Vol 1](https://opengameart.org/content/jc-sounds-fantasy-sfx-pack-vol-1), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Files were copied without modification. Credit: **JC Sounds**.
- `creatures-1/` and `creatures-2/`: rubberduck, [80 CC0 Creature SFX](https://opengameart.org/content/80-cc0-creature-sfx) and [80 CC0 Creature SFX #2](https://opengameart.org/content/80-cc0-creture-sfx-2), CC0.
- `organic-weapons/`: Vehicle, [Fantasy Weapons and Apparel SFX Library](https://opengameart.org/content/fantasy-weapons-and-apparel-sfx-library), CC0.
- `kenney-impact/`: Kenney, [Impact Sounds](https://kenney.nl/assets/impact-sounds), CC0.

If any CC BY clips are edited later, update this notice to describe the changes.
